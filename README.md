# ai_gym_fitness
# 🏋️ AI Fitness & Gym Assistant

An interactive, AI-driven fitness web application designed to act as a personal trainer, dietician, habit tracker, and gym buddy—all in one unified platform.

## 🌟 Key Features

* **📊 AI Habit Tracker & Dashboard:** Visualizes weekly workout consistency and performance metrics using Plotly, delivering actionable behavioral AI insights.
* **📷 AI Gym Trainer:** Integrates computer vision capability (MediaPipe/OpenCV ready) via camera capture to monitor exercise form, evaluate posture, and count repetitions.
* **🥗 AI Dietician & Calorie Coach:** Customizes daily diet plans and generates tailored grocery shopping lists based on BMI, dietary preferences, and fitness goals.
* **🤖 Virtual Gym Buddy:** Interactive AI companion chat interface designed to keep users motivated and offer real-time fitness guidance.
* **📍 Gym Recommender:** Suggests nearby fitness centers and localized workouts based on geographic location.

---

## 🛠️ Tech Stack

* **Frontend / Web Framework:** Streamlit
* **Data Processing & Analytics:** Pandas, NumPy
* **Data Visualization:** Plotly Express
* **Computer Vision / AI (Planned Integration):** OpenCV, MediaPipe
* **Language:** Python 3.x

## 🚀 Getting Started

### Prerequisites
Make sure you have Python installed on your machine.

Install Dependencies:
pip install streamlit pandas numpy plotly

Run the Application:
streamlit run app.py
